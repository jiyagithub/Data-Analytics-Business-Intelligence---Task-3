# 📊 Maincrafts Technology — Data Analytics & BI Internship

## Task 3: Advanced SQL Analysis, KPI Modeling & Variance Dashboard

### 🎯 Objective
Performed performance analysis and decision-support analytics using advanced SQL, Excel variance modeling, and an executive-level Tableau dashboard.

### 🛠️ Tools & Technologies Used
- **SQL** (DuckDB / sqliteonline.com) — Advanced queries
- **Microsoft Excel** — Variance & growth analysis
- **Tableau Public** — Executive dashboard
- **Dataset** — Sample Superstore (Kaggle)
  

### 🔍 What Was Done

#### Part A — Advanced SQL
- Monthly performance analysis (GROUP BY Year, Month)
- Growth rate calculation using Subqueries
- CASE statement for order classification (High/Medium/Low Value)
- Underperforming region identification using HAVING clause

#### Part B — Excel Analysis
- Monthly sales variance table (Current vs Previous Month)
- Growth % calculations using IF & SUMIFS formulas
- Category vs Profit Margin comparison table

#### Part C — Tableau Dashboard
- 5 interactive visualizations
- KPI cards: Total Sales, Profit, Customers, Orders
- Dark navy & orange executive theme

#### Part D — Business Report
- 8-section strategic analysis
- Regional, category & segment insights
- Data-driven recommendations for management
